GitHub Actions → Railway (token PROJET obligatoire)
==================================================

ERREUR "Invalid RAILWAY_TOKEN" = mauvais type de token.

❌ NE PAS utiliser :
   Avatar → Account Settings → Tokens
   (token compte / workspace — ne marche pas avec railway up en CI)

✅ UTILISER un token de PROJET :
   1. railway.com → projet "reasonable-healing" (clique le nom du projet en haut)
   2. Onglet Settings du PROJET (pas seulement le service rugtracker)
   3. Section "Tokens" ou "Project Tokens"
   4. Create Token → environnement "production"
   5. Copie le token (format xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)

   Si tu ne vois pas Tokens :
   - Service rugtracker → Settings → cherche "Project Token" / "Generate Token"
   - Ou : Cmd+K sur Railway → cherche "token"

GitHub :
   Repo rugtracker → Settings → Secrets and variables → Actions
   Secret name : RAILWAY_TOKEN
   Value : colle le token PROJET (sans guillemets, sans espace avant/après)

Push :
   git add -A && git commit -m "ci: fix railway project token" && git push origin main

Vérifier :
   GitHub → Actions → Deploy Railway → vert
   Railway → Deployments → nouveau build
